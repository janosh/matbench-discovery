# Mena

**Mena-Preview** is a 2.22M-parameter machine learning interatomic potential with a smooth 6.0 Å radial cutoff (tapering neighbor interactions between 5.0 Å and 6.0 Å), trained on MPtrj for 5.5 hours on a single NVIDIA A100-SXM4-40GB GPU and evaluated locally on an Apple M3 Max (36GB).
