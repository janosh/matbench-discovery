# EquiformerV3

EquiformerV3 is the third generation of SE(3)-equivariant graph attention Transformers. Please refer to our paper for more details.

Paper, code, and checkpoints: [equiformer_v3](https://github.com/atomicarchitects/equiformer_v3).
These variants are archived for the shared discovery runner (no stable checkpoint artifact or isolated runtime).
