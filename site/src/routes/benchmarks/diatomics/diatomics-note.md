The DFT reference curves are the lowest-energy states found for every element and spin state, cross-checked against an earlier symmetry-constrained version of the reference and screened for discontinuities. Diatomics is still a younger benchmark than discovery, so interpret small metric differences with some caution.

The PBE/r2SCAN DFT reference curves are documented in the [DFT reference provenance note](https://github.com/janosh/matbench-discovery/blob/main/site/src/lib/diatomics-dft.readme.md), including the DFT setup, spin-ladder generation, occupation seeding, sweep strategy, postprocessing, and quality checks. The [TMI page](/benchmarks/diatomics/tmi) shows each reference curve's per-atom magnetic moments vs separation, useful for spotting residual SCF spin-state artifacts and for benchmarking spin-aware MLIPs. Expert advice on how the DFT reference curves might be improved would be appreciated.

Leaderboard metrics use the [Materials Project](https://materialsproject.org) elements between H and U. Po, At, Rn, Fr, and Ra are excluded to keep the scored set compatible with MP-derived training data. Self-consistency metrics (smoothness, flips, jumps) average over this set. Reference-relative PBE errors additionally exclude curves that fail a smoothness quality gate (energy jump &ge; 1.5 eV and &ge; 3 energy-difference sign flips inside the scored window). SCF convergence issues can make these references too jumpy to score models against. Curves excluded from metrics are still shown in the plots. Models missing curves within the scored set (marked \*) are scored on their remaining elements.

With thanks to [MLIP Arena](https://huggingface.co/spaces/atomind/mlip-arena#homonuclear-diatomics) by [Yuan Chiang](https://scholar.google.com/citations?user=kZ2LfBoAAAAJ&hl=en) ([GitHub](https://github.com/chiang-yuan)), who first benchmarked MLIPs on self-consistency metrics of homonuclear diatomic curves and inspired this task.

We welcome backfill PRs from model authors for models still missing diatomic metrics; see the [diatomics runner](https://github.com/janosh/matbench-discovery/blob/main/models/run_diatomics.py), [calculator registry](https://github.com/janosh/matbench-discovery/blob/main/matbench_discovery/calculators.py), and [model enum](https://github.com/janosh/matbench-discovery/blob/main/matbench_discovery/enums.py).
